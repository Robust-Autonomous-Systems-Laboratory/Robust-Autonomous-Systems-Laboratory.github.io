# Robust Autonomous Systems Laboratory website

Website for RASL at Michigan Tech, served by GitHub Pages at
**https://robust-autonomous-systems-laboratory.github.io/**

Static HTML/CSS with no build step: edit `index.html` / `style.css`, commit, and push to `main`.

| Path | What it is |
|------|------------|
| `index.html` | The single page |
| `style.css` | Styles (light and dark mode) |
| `assets/` | Images |

Course sites and teaching tools (e.g. `/ee5531/`, `/fastslam-viz/`) are separate repositories
whose Pages live under this domain; this site only links to them.

Scope: lab research, open data, software, and teaching. Student coursework and proposals are
intentionally left out.
